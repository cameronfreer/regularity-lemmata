    Directed pair uniformity and nonuniformity witnesses #

    Pair regularity in this library is directed and phrased on ordered blocks: IsUniformPair R X Y ε says every pair of ε-large sub-blocks X' ⊆ X, Y' ⊆ Y has pair density within ε of the whole block's. Thresholds and deviations are real, with 0 < ε assumed where substantive; regularity uses ≤ ε, so failing it yields a strict witness: a NonuniformWitness records the deviating sub-rectangle as data (the refinement step needs the subsets definitionally, not just existentially).

    The predicate/negation/witness architecture follows mathlib's SimpleGraph.IsUniform / not_isUniform_iff and its chosen-witness API (Mathlib.Combinatorics.SimpleGraph.Regularity.Uniform), adapted to an arbitrary directed relation. Deliberate divergence from mathlib: mathlib defines uniformity with strict deviation < ε (failure gives ε ≤ witnesses); this library uses ≤ ε so that failure gives strict ε < witnesses — a repository API decision. Directed regularity in the literature: N. Alon and A. Shapira, Testing Subgraphs in Directed Graphs, JCSS 69 (2004), §3 (their multi-density digraph setting is stronger than the single arbitrary relation treated here).

      Type u_1

      Constructive witness that (A, B) fails ε-uniformity: an explicit pair of ε-large sub-blocks whose density deviates from the parent's by strictly more than ε.

      • left : Finset α

        The sub-rectangle's left side, ⊆ A.

      • right : Finset α

        The sub-rectangle's right side, ⊆ B.

      • left_subset : self.left ⊆ A
      • right_subset : self.right ⊆ B
      • left_card : ε * ↑A.card ≤ ↑self.left.card

        left is ε-large in A.

      • right_card : ε * ↑B.card ≤ ↑self.right.card

        right is ε-large in B.

      • dev : ε < |pairDensity R self.left self.right - pairDensity R A B|

        The density deviation strictly exceeds ε.
