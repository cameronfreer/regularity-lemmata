    Heterogeneous tuple boxes and lower faces #

    Finite tuples live in boxes Fintype.piFinset A for A : Fin k → Finset α. This file provides the coordinate-deletion operation on tuples (lowerFace, via Fin.succAbove), its computed behavior at arity 3, and the identification of Fin 2-boxes with binary products via mathlib's finTwoArrowEquiv.

    Mathlib provides the box itself (Fintype.piFinset), its cardinality (Fintype.card_piFinset), and the pair equivalence (finTwoArrowEquiv); this file only adds the glue used by the density and counting layers.
