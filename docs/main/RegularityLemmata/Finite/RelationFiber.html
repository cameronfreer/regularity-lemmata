    Finite relation fibers #

    The trace of one row of a heterogeneous binary relation on a supplied finite support, and the finite family of traces generated by a finite set of rows. These are set-system objects: no graph, model, regularity, or stability structure is assumed.

    The support is explicit. This keeps the definitions useful on infinite ambient types and makes the empty-support endpoint honest: every fiber on ∅ is ∅, while a nonempty row set generates the singleton family {∅}.
