    Engel-form (Titu) inequalities under the division convention #

    The Cauchy–Schwarz quotient inequality (∑ f)² / (∑ g) ≤ ∑ f² / g in the form used by the energy calculus: denominators are only assumed nonnegative, with the convention hypothesis g i = 0 → f i = 0 making the x / 0 = 0 cases degenerate rather than false.

    Mathlib proves the strictly-positive-denominator form (Finset.sq_sum_div_le_sum_sq_div); this file wraps it, splitting off the zero-denominator indices. The two- and three-term forms are instantiations.

    source
    theorem RegularityLemmata.titu_finset {ι : Type u_1} [DecidableEq ι] (f g : ι → ℝ) (I : Finset ι) (hg : ∀ i ∈ I, 0 ≤ g i) (hfg : ∀ i ∈ I, g i = 0 → f i = 0) :
    (∑ i ∈ I, f i) ^ 2 / ∑ i ∈ I, g i ≤ ∑ i ∈ I, f i ^ 2 / g i

    Engel form / Titu's lemma over a finset, with nonnegative denominators and the x / 0 = 0 convention hypothesis.

    source
    theorem RegularityLemmata.sq_sum_mul_le_sum_mul_sum_sq_mul {ι : Type u_1} [DecidableEq ι] (a m : ι → ℝ) (I : Finset ι) (hm : ∀ i ∈ I, 0 ≤ m i) :
    (∑ i ∈ I, a i * m i) ^ 2 ≤ (∑ i ∈ I, m i) * ∑ i ∈ I, a i ^ 2 * m i

    Mass-weighted Cauchy–Schwarz. A mass-weighted average is dominated by the mass-weighted mean square, in the denominator-free form the energy calculus wants: (∑ aᵢ mᵢ)² ≤ (∑ mᵢ) · ∑ aᵢ² mᵢ.

    Only nonnegativity of the masses is assumed — no positivity, and no convention hypothesis, because the mᵢ = 0 indices drop from both sides on their own. This is the form that turns a large rectangle error into an energy increment.

    source
    theorem RegularityLemmata.abs_mul_sub_mul_le {x y d e : ℝ} (hx : |x| ≤ 1) (he : |e| ≤ 1) :
    |x * y - d * e| ≤ |x - d| + |y - e|

    Two-factor perturbation bound: replacing each factor of a product by a nearby value perturbs the product by at most the sum of the factor errors, provided the retained factors x and e have absolute value at most one (densities are in [0,1]). Consumed by path and triangle counting.

    source
    theorem RegularityLemmata.abs_mul_mul_sub_mul_mul_le {a b c a' b' c' : ℝ} (hb : |b| ≤ 1) (hc : |c| ≤ 1) (ha' : |a'| ≤ 1) (hb' : |b'| ≤ 1) :
    |a * b * c - a' * b' * c'| ≤ |a - a'| + |b - b'| + |c - c'|

    Three-factor perturbation bound: replacing each factor of a triple product by a nearby value perturbs the product by at most the sum of the three factor errors, given the retained factors have absolute value at most one. Consumed by strong three-vertex counting.

    Bilinear domination by 0/1 rectangles #

    A [0,1]-weighted bilinear combination of a matrix's entries is bounded by the largest 0/1 combination — that is, by the sup over genuine sub-rectangles. Stated abstractly here because the hypotheses mention only a real matrix and two coefficient vectors.

    This is the load-bearing step behind contraction of a stepped rectangle sum, where the coefficients are relative cell masses. Note the constant: the bound is ε, not 2ε — no extreme-point machinery is needed, because cᵢ * yᵢ ≤ max yᵢ 0 holds pointwise.

    source
    theorem RegularityLemmata.sum_mul_le_sum_filter_nonneg {ι : Type u_1} [DecidableEq ι] {c : ι → ℝ} (I : Finset ι) (hc0 : ∀ i ∈ I, 0 ≤ c i) (hc1 : ∀ i ∈ I, c i ≤ 1) (y : ι → ℝ) :
    ∑ i ∈ I, c i * y i ≤ ∑ i ∈ I with 0 ≤ y i, y i

    A [0,1]-weighted sum is dominated by the sum over its nonnegative part — the 0/1 choice cᵢ = 1 ↔ 0 ≤ yᵢ.

    ∑ i ∈ I with y i < 0, y i ≤ ∑ i ∈ I, c i * y i

    The mirror bound, with the 0/1 choice cᵢ = 1 ↔ yᵢ < 0.

    theorem RegularityLemmata.abs_sum_bilinear_le {ι : Type u_1} {κ : Type u_2} [DecidableEq ι] [DecidableEq κ] {c : ι → ℝ} {d : κ → ℝ} (I : Finset ι) (J : Finset κ) (hc0 : ∀ i ∈ I, 0 ≤ c i) (hc1 : ∀ i ∈ I, c i ≤ 1) (hd0 : ∀ j ∈ J, 0 ≤ d j) (hd1 : ∀ j ∈ J, d j ≤ 1) (x : ι → κ → ℝ) {ε : ℝ} (hrect : ∀ I' ⊆ I, ∀ J' ⊆ J, |∑ i ∈ I', ∑ j ∈ J', x i j| ≤ ε) :
    |∑ i ∈ I, c i * ∑ j ∈ J, d j * x i j| ≤ ε

    Bilinear domination, at constant 1. If every sub-rectangle sum of x is within ε, then so is every [0,1]-weighted bilinear combination.

    The 1 here is what keeps the downstream common-refinement constant at 2 rather than 4: contraction is free, and the only factor of two comes from a triangle inequality.

    The exponential inequality behind multiplicative weights #

    source
    theorem RegularityLemmata.exp_neg_le_one_sub_add_sq_half {x : ℝ} (hx : 0 ≤ x) :
    Real.exp (-x) ≤ 1 - x + x ^ 2 / 2

    exp (−x) ≤ 1 − x + x²/2 for x ≥ 0. The reverse-direction companion of Mathlib's series bound Real.quadratic_le_exp_of_nonneg (1 + x + x²/2 ≤ exp x), from which it follows since (1 − x + x²/2)·(1 + x + x²/2) = 1 + x⁴/4 ≥ 1. This is the single analytic ingredient of the Hedge regret bound (RegularityLemmata/Finite/Hedge.lean); Mathlib's pin has only the forward bound. Recorded on the plausibly-Mathlib-shaped list (#54).
