    Finite traces and VC bounds #

    This file builds a support-sensitive trace API on Mathlib's finite set-family definitions. Mathlib already supplies Finset.Shatters, Finset.shatterer, Finset.vcDim, Pajor's inequality Finset.card_le_card_shatterer, and the Sauer–Shelah theorem. No parallel VC dimension is defined here.

    The added content is the finite restriction interface and the estimates whose ambient size is the tracing support s.card, even when the ambient type is infinite. The latter uses Mathlib's Pajor inequality, powersetCard enumeration, and the full binomial-sum identity.

      Support-sensitive Sauer–Shelah bound for a family all of whose members lie in s.

      Mathlib's Finset.card_shatterer_le_sum_vcDim counts against an entire finite ambient type. This adapter works on an arbitrary ambient type and counts only the supplied finite support: Pajor's inequality embeds 𝒜 into its shatterer, and every shattered set lies in the union of the appropriate powersetCard slices of s.
