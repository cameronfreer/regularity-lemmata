    The proportional sampling form for traces #

    The sampling route runs INSIDE each parent cell and only needs, for every trace (test set) C in the complement-closed trace family, an UPPER proportional window |C ∩ block| ≤ |C|·s/n + t: the closure supplies the complement of each trace, so one-sided control of every closure member yields two-sided control of every raw trace — and downstream transfer arguments consume exactly the cross-multiplied form n·|C ∩ B| ≤ s·|C| + ζ·n·s.

    Contents: the specialization of exists_equiv_forall_blocks_window to one-sided upper windows (the lower-violation families are literally empty at lo = 0, halving the event count), and the pure arithmetic bridge from the ℕ-division window to the real-valued cross-multiplied trace estimate.

    The cross-multiplied trace estimate. The ℕ-division upper window TB ≤ TA·s/n + t with slack t ≤ ζ·s yields the real-valued form n·TB ≤ s·TA + ζ·n·s consumed by the sampled-line transfer downstream.
