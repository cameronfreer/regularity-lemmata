    Extension counts for pattern assignments #

    An assignment x : Fin n -> Fin k fixes every vertex in its image, not just one vertex. The free exponent is therefore k - |image x|. The statement includes empty assignments and repeated coordinates; no positivity premise is needed. This is a tuple-counting estimate, not a diagonal-edit bound.

    source
    theorem RegularityLemmata.card_filter_comp_mem_le_image {α : Type u_1} [DecidableEq α] {k n : ℕ} (s : Finset α) (E : Finset (Fin n → α)) (x : Fin n → Fin k) :
    {f ∈ Fintype.piFinset fun (x : Fin k) => s | f ∘ x ∈ E}.card ≤ E.card * s.card ^ (k - (Finset.image x Finset.univ).card)

    Pinning all coordinates touched by an assignment saves one power per distinct image vertex. The existing one-coordinate bound remains unchanged.

    {f ∈ Fintype.piFinset fun (x : Fin k) => s | f ∘ x ∈ E}.card ≤ E.card * s.card ^ (k - n)

    In a non-diagonal assignment all n arguments are distinct, giving exponent k-n. This bound itself imposes no simplicity assumption on a relation.
